## ✨ Features

- 🎨 **Modern Dark UI** — Elegant dark theme with gradient accents and animated blobs
- ⌨️ **Typing Animation** — Auto-cycling role text in the hero section
- 📱 **Fully Responsive** — Mobile-first design with a hamburger menu
- 🔍 **Scroll Reveal** — Sections animate into view using IntersectionObserver
- 🧩 **Multi-section Layout** — Hero, About, Skills, Projects, Education, Contact
- ⚡ **Zero Dependencies** — No npm, no build step, just open `index.html`

## 🎨 Customization

Want to use this as your own portfolio? Here's what to change:

1. **`index.html`** — Replace name, bio, project details, and social links
2. **`style.css`** — Tweak `--accent` and `--accent2` CSS variables for your color scheme
3. **`my_photo.jpg`** — Swap in your own photo

Key CSS variables (at the top of `style.css`):
```css
--accent:   #6c63ff;   /* Primary purple */
--accent2:  #ff6584;   /* Pink highlight */
--bg:       #0d0d0d;   /* Page background */
```
